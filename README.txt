BRIGHTWAY.VIP – EENVOUDIGE TWEETALIGE WEBPAGINA

INHOUD
- index.html: complete Nederlandse/Engelse website
- assets/brightway-logo.webp: logo op witte achtergrond
- assets/favicon.svg: klein browsericoon

Lokaal bekijken: open index.html in een browser.

Gratis publiceren via GitHub Pages:
1. Maak een PUBLIC repository, bijvoorbeeld brightway-site (gratis GitHub Pages vereist doorgaans public repository bij gratis accounts).
2. Upload index.html en de map assets naar de hoofdmap.
3. Ga naar Settings > Pages. Kies Deploy from a branch > main > /(root) > Save.
4. Vul bij Settings > Pages > Custom domain in: brightway.vip.
5. Pas pas daarna bij Namecheap de vereiste A-records voor @ en CNAME voor www aan volgens de ACTUELE GitHub Pages-documentatie. Wijzig geen bestaande MX, SPF, DKIM of DMARC records. Controleer eventuele bestaande A/CNAME voor @/www eerst.
6. Zet na domeinvalidatie 'Enforce HTTPS' aan.

LET OP
- Er zijn nog geen wijzigingen aangebracht aan Namecheap of GitHub.
- Controleer alle inhoud en het e-mailadres vóór publicatie.
- De site gebruikt geen cookies, trackers of externe scripts.
- Juridische verplichtingen (zoals eventuele verdere bedrijfsinformatie) kunnen afhangen van het daadwerkelijke gebruik van de site.
